# Sample images

Real sample images for the live demos / practicals, from the book's official
data repository:

- Source: https://github.com/bioimagebook/practical-data (branch `main`)
- Part of Pete Bankhead's *Introduction to Bioimage Analysis* (CC-BY 4.0).

These are the files the book's practicals refer to (Spooked.tif,
Neuron-composite.tif, cell_outlier.tif, similar_1..4.tif, …). The tutor lists
them with `list_sample_images()` and uses their absolute paths in demonstrations.
