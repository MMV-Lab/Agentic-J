# CLIJ2 — complete operation reference (installed build)

All **451 CLIJ2 operations** of the installed `clij2_-2.5.3.5.jar`, generated by reflecting
over the jar in this container, grouped by their menu category. The Groovy call is
`clij2.<op>(<parameters>)`; the macro/menu name is `CLIJ2_<op>`.

**Reading the parameter column:** `→` marks a **destination image you must allocate yourself**
(`clij2.create(...)`) before the call. Everything else is an input image or a number.
`dims` is what the op supports (2D, 3D, or both).

For the semantics of an individual op (formula, typical parameter values, worked example)
see <https://clij.github.io/clij2-docs/reference> — the same text is available offline via
`op.getDescription()` (see `GROOVY_API.md` §10).

⚠ Ops listed here that are `@Deprecated` in this build: `affineTransform`, `blur2D`, `blur3D`,
`blur3DSliceBySlice`, `connectedComponentsLabeling`, `detectMaximaBox`, `detectMinimaBox`,
`drawMeshBetweenNClosestLabels`, `getSize`, `image2DToResultsTable`, `resultsTableToImage2D`,
`rotateLeft`, `rotateRight`, `scale`. See `GROOVY_API.md` §9 for replacements.
